# OJUEWA — The Art of Becoming

Premium Nigerian beauty studio website built with Next.js App Router, TypeScript, and responsive editorial styling.

## Development

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Features
- Editorial homepage and responsive navigation
- Makeup, hair, nails and pedicure service explorer
- Gallery with category filters
- Interactive mirror comparison demonstration (not a real client transformation)
- Appointment request and contact forms

## Important
Portfolio photography is illustrative, not verified OJUEWA client work. Appointment requests are not confirmed bookings. Add verified business information and arrange durable data storage and notification delivery before production use.
